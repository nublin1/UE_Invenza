# Списочное представление любого контейнера

`WBP_InventoryListView` показывает существующий `UInventoryBase` списком только для просмотра. Один и тот же виджет принимает `USlotbasedInventory` (включая склад) и `UListInventory`. Исходный контейнер сохраняет свой тип и способ хранения.

## Подключение в Blueprint

1. Создайте виджет класса `/InventorySystemInvenzaPlugin/UI/Inventory/Views/WBP_InventoryListView` через **Create Widget** или добавьте его в свой Widget Blueprint.
2. Получите нужный контейнер из `InventoryCollectionComponent` через **Get Inventory By Tag** или **Get Inventory By ID**. Передавайте именно контейнер, а не массив предметов и не существующий интерактивный виджет.
3. Вызовите у списка **Set Source Inventory**, передав полученный `InventoryBase`. Это можно сделать до добавления на экран или после него.
4. Для смены контейнера снова вызовите **Set Source Inventory**. Для явного отключения передайте `None`. При удалении виджета с экрана он отписывается от событий; при повторном открытии подключается к актуальным данным.

Список не регистрируется как основной UI контейнера. Его можно открыть одновременно с обычной сеткой или другим экземпляром списка.

## Поиск, сортировка и строки

- Поле поиска ищет по отображаемому названию, без учёта регистра. **Set Search Text** задаёт тот же фильтр из Blueprint.
- Кнопка с `A–Z` переключает сортировку названий по возрастанию и убыванию. Кнопка со стрелкой вниз сортирует по количеству, начиная с большего. Назначение и состояние показаны в подсказках.
- **Set Sort Mode** также поддерживает `SourceOrder`, возвращающий порядок выдачи коллекции. Ни один режим не вызывает сортировку самого инвентаря.
- **Set Category Filters** принимает `GameplayTagContainer`. Пустой набор показывает все категории; выбранный тег включает дочерние категории. Фильтр категории и поиск применяются вместе.
- Одна строка соответствует одному существующему стеку. Одинаковые предметы из разных стеков не объединяются. Название и количество находятся в отдельных полях.
- **Get View Entries** возвращает все локальные строки, **Get Visible Entries** — результат фильтра и сортировки, **Get Selected Entry** — выбранную строку. У строки доступны **Get Item** и **Get Source Inventory**.

Фильтры и объекты строк принадлежат конкретному виджету. Два окна одного контейнера не перезаписывают настройки друг друга. При обычном обновлении сохраняются объекты оставшихся строк; выбор и прокрутка сохраняются, пока выбранная строка остаётся в списке.

## Обновление и границы доступа

Список подписывается на события контейнера, коллекции и предметов. Несколько событий объединяются в обновление на следующем кадре. Изменение количества явно уведомляет существующую строку; виртуализация `ListView` сохраняется. Восстановление сохранения и уведомления клиентской репликации используют те же подписки. Проверки инвентаря каждый Tick нет.

Виджет поддерживает выделение и существующую подсказку `WBP_ItemTooltip`. В нём нет переноса, быстрого перемещения, использования, разделения, выбрасывания, уничтожения или изменяющего контекстного меню. Перетаскивание предмета на эту область поглощается без операции с предметом, чтобы запрос не попал в интерактивный контейнер под списком.

Представление не создаёт `UInventorySlotData` и `UInventoryListEntry`, не изменяет слоты, координаты, резервы, вместимость, состав, визуальные связи или регистрацию основного UI. `UInventoryViewEntry` — локальные временные объекты; они не реплицируются и не сохраняются. Ссылки на исходный контейнер и предметы слабые. Завершение жизни владельца отключает источник и очищает строки.

Режим просмотра относится к UI. Сервер должен отдельно разрешать доступ к данным. Виджет показывает только данные контейнера, уже доступные этому клиенту; он не запрашивает закрытое хранилище и не выдаёт права доступа.

Прямое присваивание количества без какого-либо события не обновляет UI автоматически. Используйте обычные операции Invenza, соответствующее уведомление предмета/коллекции или явный **Refresh View** после собственной пакетной операции.

## Настройка внешнего вида

Нативные классы: `UInventoryListViewWidget`, `UInventoryListViewRowWidget`, `UInventoryViewEntry`. Новый layout находится только в `WBP_InventoryListView` и `WBP_InventoryListViewRow` в `UI/Inventory/Views`. Строка переиспользует Core-виджет `WBP_LabelBaseText` и существующую подсказку. Кнопки переиспользуют `WBP_UIButtonWithSlot`; тексты их подсказок — редактируемые `FText`-свойства списка.

Существующие `WBP_ListInv`, `WBP_ListInvSlot`, их нативные классы и карты не требуют изменений. Это самостоятельное представление, которое подключается в нужном экране проекта.
