# Общая тема интерфейса

## Где менять оформление

Открой `InventorySystemInvenzaPlugin/Data/UI/DA_UITheme_Default`. Ассеты плагина видны при включённом **Show Plugin Content**.

- **Palette** — цвета по ролям: `Text.Primary`, `Text.Secondary`, `Panel.Background`, `Panel.Inset`, `Panel.Row`, `Frame.Standard`, `Button.Normal`, `Button.Hovered`, `Button.Pressed`, `Button.Selected`, `Drop.Valid`, `Drop.Invalid`, `Drop.Partial`, `Progress.Fill`, `Progress.Track`.
- **Default Font** — общий шрифт. Записи **Typography** с `Use Default Font` используют его; остальные сохраняют собственный Font Object. Typography также хранит размер, начертание и outline.
- **Brushes** — декоративные кисти рамок, кнопок, полос прокрутки, прогресса и значков состояния. `Color Role` ссылается на Palette: менять один цвет в каждой кисти отдельно не требуется.

Тема по умолчанию повторяет существующее оформление. Отдельные прежние оттенки и варианты шрифтов сохранены отдельными ролями. Дополнительные роли `Text.Queue`, `Slider.Track`, `Frame.Inventory`, `Color.Gray…` и `Color.LegacyMagenta` сохраняют старые варианты; это явные именованные роли, а не поиск цвета во время игры.

Тема выбирается в **Project Settings → Game → Invenza Inventory → Interface → Theme → UI Theme**. Для своего проекта создай копию Data Asset и назначь её здесь. Настройка хранится в `Config/DefaultInventorySystemInvenzaPlugin.ini`; исходная тема плагина не содержит обязательных ссылок на `/Game`.

Старые Default UI Font / Default Text Color и четыре размера в **Legacy Appearance** действуют только при отсутствии темы. При выбранной теме шрифт и цвета берутся из неё.

## Виджеты и локальные исключения

В Class Defaults и у экземпляра базового виджета есть **Theme Source**:

- **Theme** — применять все перечисленные привязки.
- **Theme With Overrides** — пропускать привязки с флагом **Override Locally**.
- **Local** — сохранять собственные настройки виджета.

Каждая запись **Theme Bindings** явно указывает `Widget Name`, `Property Path` и `Role`. Пустое имя означает сам UserWidget; непустое — компонент в его собственном WidgetTree. Примеры: `Color`, `FontInfo`, `LeftBorderStyle.BrushColor`, `WidgetStyle.Normal`. У вложенного Core-виджета настраивай его собственные bindings: имя из внешнего дерева не адресует внутренности вложенного UserWidget.

Для локального цвета подписи выбери Theme With Overrides, отметь Override Locally у `Color` и задай Color. Для локального шрифта аналогично используй `FontInfo`. Не удаляй остальные привязки, если они должны продолжать получать тему.

Все существующие базовые элементы и окна Invenza подключены к теме, включая инвентари, списки, экипировку, склад, торговлю, крафт, модальные окна, подсказки, справку, сохранения и frontend примера. Новый собственный Widget Blueprint наследуй от `UInvenzaBaseWidget` либо соответствующего Core-класса и добавляй явные привязки. Сам факт наследования не назначает роли неизвестным новым элементам.

## Предпросмотр и обновление данных

Открой `UI/Theme/WBP_UIThemePreview`: там есть текст, русский текст, поле ввода, обычная кнопка, toggle, недоступная кнопка и прогресс. Меняй тему в редакторе — открытые Designer-превью получают оформление без GameInstance и игрока. При изменении структуры своего Blueprint перекомпилируй именно его.

Тема применяется при создании/синхронизации виджета; Tick не используется. Загрузка выбранного Data Asset выполняется централизованно и кешируется Engine Subsystem. Горячее переключение темы в запущенной игре не является отдельным пользовательским режимом.

`UpdateText` меняет содержимое подписи. `UpdateAppearance` меняет её оформление без присваивания текста. Старый `UpdateTextAndFont` оставлен для совместимости и явно меняет обе части; передавай в него уже оформленный стиль владельца. Явные вызовы UpdateFont / UpdateAppearance / UpdateTextAndFont отмечают соответствующие поля экземпляра как локальные переопределения: стиль, переданный владельцем до добавления в layout, не сбрасывается при Construct. Источник стиля владельца продолжает получать тему; его appearance-событие обновляет потомков без замены текста. Для возврата к привязке сбрось Override Locally либо выбери Theme. Для Blueprint-логики пользовательских состояний доступны Theme Color / Theme Slate Color / Theme Font / Theme Brush с ролью и локальным fallback.

## Границы темы

Тема не меняет Visibility, RenderOpacity, alpha существующих цветов, hit testing, фокус, доступность действий, размеры сетки, расположение слотов или отступы layout. Альфа Palette не заменяет альфу существующего элемента. Размер шрифта и декоративная кисть влияют на отрисовку; выбирай их с учётом пространства в собственном layout.

Иконки предметов, динамические материалы, изображения персонажей и содержимое полей не заменяются ресурсами темы. Состояния toggle, drag-подсветка и прогресс используют свои роли; выбор и игровые данные остаются у соответствующих виджетов.

## Упаковка

Выбранная в Project Settings тема добавляется плагином в список пакетов для cook. Её Font Object и ресурсы Brushes — обычные зависимости Data Asset. Дополнительного Always Cook для каждой новой темы не требуется. Preview — инструмент редактора, его не нужно добавлять в игровой layout.

Сценарии миграции и проверки находятся в `Scripts/UI/*ui_theme*.py` в Example Project. Они не являются runtime-зависимостями плагина. Резервные копии и отчёты конкретного переноса находятся в `Saved/UITheme20261031` и не входят в поставку.

## Локальные настройки и проверка привязок

Авторские Color, FontInfo, BrushStyle и остальные параметры UserWidget теперь сохраняются отдельно от вычисленного оформления. Local восстанавливает актуальные локальные значения; Theme берёт значения из темы, а при недостающей роли использует локальное значение. Theme With Overrides учитывает явные исключения. Изменение авторских полей во время предпросмотра не теряется после возврата к Local.

Для обычных UMG-компонентов базовый виджет хранит отдельные типизированные исходные значения. Редакторские изменения обновляют только изменённые поля, сохраняя остальные локальные параметры. Тема не присваивает свои результаты авторским свойствам самого UserWidget. В C++ при чтении собственных параметров оформления используй ResolveThemeColorForProperty, ResolveThemeFont, ResolveThemeSlateColor, ResolveThemeBrush либо ResolveThemeStyle для копии структуры. Обновление темы выполняет RefreshThemeAppearance без изменения содержимого.

В плагин входит редакторный модуль InvenzaUIThemeEditor. Стандартная проверка ассетов Unreal проверяет Widget Blueprint, включая вложенные Core-элементы: существование элемента и пути, тип свойства и роль в правильном разделе, дубли и пересечения целого свойства с вложенным. Диагностика содержит имя Blueprint, виджет, путь и роль. Проверка запускается также перед cook; ошибочные привязки выдаются как ошибки упаковки. В runtime одинаковая ошибка выводится один раз для класса/привязки/темы, а оформление использует локальный fallback. Проверка не компилирует и не сохраняет ассеты.

Обычный фон toggle вычисляется из локальных параметров или успешного разрешения роли. Он не считывается из текущего выбранного состояния. При удалении роли выключение возвращает локальный фон; обновление оформления не вызывает OnToggled или OnButtonClicked.
