# Дистанция активного взаимодействия

Язык: **Русский** | [English](../en/InteractionDistance.md)

Глобальная настройка: ассет
`/InventorySystemInvenzaPlugin/Data/Settings/InvenzaSettings`,
раздел **Interaction → Max Interaction Distance**. Ассет выбирается в
Project Settings → Invenza Inventory → Inventory Settings Asset.

Значение по умолчанию — **600 см**. Расстояние считается в 3D между позициями
акторов участника и объекта. Граница включительна: прекращение происходит при
превышении значения. Настройка не меняет дальность трассировки/обнаружения.
У `StorageAccessPoint` дополнительно остаётся собственное ограничение доступа
`MaxUseDistance`.

Сервер проверяет активное взаимодействие таймером каждые **0,25 с**. После
завершения таймер выключается. Отход участника, перемещение объекта за пределы
дистанции и уничтожение объекта завершают взаимодействие через `StopInteract`.
Клиент получает завершение с номером сеанса, чтобы запоздавшее сообщение не
закрыло повторно открытое взаимодействие.

Для контейнера, торговца и точки доступа отзываются ссылки на внешние инвентари;
интерфейс закрывается существующими уведомлениями. У станка снимается только
оператор, зарегистрированный данным участником. Закрытие панели само по себе
не очищает очередь крафта; станок, требующий оператора, сохраняет обычные правила
блокировки при отсутствии операторов.

Логика не зависит от камеры или контроллера игрока. Взаимодействия NPC через
`InteractionComponent` используют тот же механизм. Вызовы серверных обработчиков
`UIInventoryManager` без `InteractionComponent` используют резервный таймер с тем
же глобальным ограничением. Для собственного C++-сценария, который открывает
длительное взаимодействие в обход стандартного `Interact`, после успешного
начала вызовите `TrackActiveInteraction(Target, Type)` на сервере и используйте
`StopInteract` для завершения.

Автотест: `Invenza.Interaction.Range`.

Исторические имена автотестов относятся к проверкам, исходники которых удалены по запросу владельца. В текущей поставке их нет; используйте описанные ручные сценарии.
