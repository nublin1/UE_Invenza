# Пополнение хранилища

Язык: **Русский** | [English](../en/RestockStorage.md)

Кнопка `+=` в `WBP_Inventory_OperationsPanel`, рядом с «Положить всё», переносит из основного инвентаря игрока все стаки тех типов, которые уже присутствуют в открытом хранилище.

Типы фиксируются в начале операции и сравниваются по `ItemID`, как в существующей функции `bIsSameItems`. Пустое хранилище ничего не принимает через эту кнопку. Подходящие предметы могут объединяться с существующими стеками и занимать новые ячейки. Перенос выполняется через `ItemTransferRequest`: непоместившееся количество остаётся в источнике.

В Blueprint доступен вызов `UIInventoryManager.TransferMatchingItems(SourceInventory, TargetInventory)`. Источником может быть другой доступный инвентарь. Оба инвентаря должны принадлежать коллекции игрока, быть текущим открытым внешним инвентарём либо входить в разрешённый сеанс общего склада. Запрос клиента повторно проверяется на сервере. Торговля и контейнеры ссылок исключены из этой операции.

В пользовательскую панель операций можно добавить Core-кнопку с именем `Button_PlaceMatching`: `UInventoryContainerWidget` автоматически привяжет действие. Подсказка текущей кнопки находится в `WBP_Inventory_OperationsPanel`. Для подписи `PlaceMatchingLabel` используется `+=`; её шрифт и цвет задаются в `Restock Label Style` класса панели операций. По умолчанию используется Roboto.

Автотест: `Invenza.Inventory.TransferMatchingItems`.

Исторические имена автотестов относятся к проверкам, исходники которых удалены по запросу владельца. В текущей поставке их нет; используйте описанные ручные сценарии.
