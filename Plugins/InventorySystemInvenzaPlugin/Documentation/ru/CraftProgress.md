# Прогресс крафта

Язык: **Русский** | [English](../en/CraftProgress.md)

В очереди и над станцией используется общий Core-виджет
`/InventorySystemInvenzaPlugin/UI/Core/Progress/WBP_CraftProgressDisplay`.
По умолчанию обе панели показывают полосу с процентами. Прогресс относится к
текущему экземпляру предмета, а Remaining показывает оставшееся количество.

## Настройки отображения

- Очередь: открой `WBP_QueueCraftList_Dashboard` → Class Defaults → Queue → Progress → Progress Settings.
- Панель над станцией: `WBP_WorldCraftState` → Class Defaults → World Craft → Progress → Progress Settings.

| Use Progress Bar | Show Percentage | Отображение |
| --- | --- | --- |
| Включено | Включено | Полоса и проценты |
| Включено | Выключено | Только полоса |
| Выключено | Включено | Только проценты |
| Выключено | Выключено | Выполненная / требуемая работа, например 2 / 5 |

Параметры независимы для очереди и мирового виджета. Во время игры их можно
менять функцией `SetProgressDisplaySettings`; текущее значение сохраняется.
Обновление работает через существующие события очереди и станции, без Tick.
Станция привязывает компонент к мировому виджету после своей инициализации
для одиночной игры и хоста, а на клиентах — при репликации ссылки. При её
сбросе виджет отписывается от прежнего компонента и скрывается.

## Внешний вид

- Цвет заполнения, цвет дорожки, высота полосы, шрифт и цвет текста:
  `WBP_CraftProgressDisplay` → Class Defaults → Craft Progress → Appearance.
- Для локальной настройки можно выбрать экземпляр `CraftProgress` в Designer
  строки очереди или `WBP_WorldCraftEntry` и поменять эти свойства там.
- Фон, рамка и внутренние отступы мировой панели:
  `WBP_WorldCraftState` → Class Defaults → World Craft → Appearance.
- `WBP_WorldCraftEntry` — локальный вариант строки для мира с более крупным
  названием. Общий `WBP_QueueCraftList_ItemBasic` не изменён.

Ширина мировой панели — 250 Slate units. В `WBP_WorldCraftState` контейнер
`SizeBox_28` расположен по центру `WorldCraftLayout`, поэтому панель занимает
половину стандартной поверхности WidgetComponent шириной 500. Шрифт и высота
панели не уменьшаются. Ширина меняется в Designer у `SizeBox_28` → Width Override.

Пустая станция скрывает всю мировую панель, включая фон. При переходе к
следующему предмету полоса получает его прогресс. Значение ограничено диапазоном
0–100%; при нулевом объёме работы показывается 0%, без деления на ноль.

## Проверка

Автотест: `Invenza.UI.CraftProgress`.
Интеграционная проверка настоящей станции в PIE: `Invenza.UI.WorldCraftStation`.

Для внеэкранного предпросмотра запусти `Scripts/UI/preview_craft_progress.py`
через `-ExecutePythonScript` в обычном редакторе с `-RenderOffscreen`.
Снимки четырёх режимов сохраняются в `Saved/CraftProgress/` без сохранения ассетов.

`Scripts/UI/update_craft_progress.py` создаёт Core-компонент и локальную строку
для мира, обновляя только строку очереди и мировой виджет. Существующие файлы
перед сохранением копируются в `Saved/CraftProgress/Before/`.

Исторические имена автотестов относятся к проверкам, исходники которых удалены по запросу владельца. В текущей поставке их нет; используйте описанные ручные сценарии.
