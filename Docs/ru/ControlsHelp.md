# Справка по управлению

Язык: **Русский** | [English](../en/ControlsHelp.md)

В игре нажмите **F6**, чтобы открыть `WBP_ControlsHelp` на уровне модальных окон.
Окно содержит прокручиваемый список «действие — клавиши» и кнопку **OK**.
Закрыть его также можно клавишами Escape и Enter. Предыдущее модальное окно
сохраняется и снова показывается после закрытия справки.

Blueprint находится в плагине: `UI/Controls/WBP_ControlsHelp`.
Используются существующие Core-виджеты текста, рамки и кнопки.

Шрифт, размер и цвет динамических строк настраиваются в **Class Defaults**
`WBP_ControlsHelp`, раздел **Controls Help → Appearance**: `Row Style` для действий
и клавиш, `Heading Style` для заголовков групп. Поле `Text` в этих стилях заменяется
текстом строки при построении списка. По умолчанию используется Roboto из Unreal.

## Настройка

Откройте `/InventorySystemInvenzaPlugin/Data/Settings/InvenzaSettings`, раздел
**Controls Help**:

- `Controls Help Widget Class` — класс окна.
- `Controls Help Action` — действие открытия. По умолчанию `IA_ControlsHelp`,
  назначенное на F6 в `Input/InputMappingInventoryContext`.
- `Include Inventory Controls` — собирать команды из текущего персонажа:
  `UIInventoryManager.UISettings`, `InteractionComponent.KeyBindings` и действия
  быстрых слотов его инвентарей.
- `Additional Controls` — дополнительные строки: группа, название и Input Action.
  В примере добавлены движение, обзор, прыжок и команды Take all / Place all. Для другого персонажа укажите
  Input Actions, используемые именно вашим персонажем.

Физические клавиши в строках не задаются. При открытии берутся текущие активные
назначения Enhanced Input соответствующего локального игрока. Несколько
назначений показываются через `/`, сочетания — через `+`. Для действий без
действующего назначения отображается `Unassigned`. Кнопки мыши инвентаря берутся
из `UISettings`, поскольку они настроены как `FKey`, а не Input Actions.

Для открытия из собственной кнопки вызывайте `UIInventoryManager.ShowControlsHelp`
либо `ModalWindowManager.ShowControlsHelp` у локального игрока. При собственном
Mapping Context добавьте в него `Controls Help Action`: менеджер не назначает
физическую клавишу принудительно.

Проверка: `Invenza.UI.ControlsHelp` — действующие клавиши, переназначение,
клавиатура и геймпад, сочетания, отсутствие назначения, модальный стек и OK.

Исторические имена автотестов относятся к проверкам, исходники которых удалены по запросу владельца. В текущей поставке их нет; используйте описанные ручные сценарии.
